Getting started

Four commands between you and production.

Clone it, point it at your own AWS account, and watch the state file fill up.

01 terraform init

Pulls the AWS provider and wires up remote state.

02 terraform plan

Shows exactly what's about to exist. No surprises.

03 terraform apply

Bucket, distribution, and DNS record — created in order.

04 git push origin main

CI takes over from here. Every push re-applies and syncs the site.
